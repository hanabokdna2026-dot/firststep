# 풍성한 첫걸음 — 앱 구조 문서

> 이 문서는 앱 안에 들어 있는 모든 콘텐츠와 동작 방식을 한눈에 파악할 수 있도록 정리한 자료입니다.
> 콘텐츠 수정 시 이 문서를 보면서 어디를 어떻게 손볼지 결정할 수 있습니다.

---

## 1. 앱 기본 정보

| 항목 | 내용 |
|---|---|
| 앱 이름 | 풍성한 삶으로 첫걸음 (홈 화면: 풍성한 첫걸음) |
| 부제 | 풍성한 삶으로 한 걸음씩 함께 |
| 대상 | 새신자 (제자훈련 보조 도구) |
| 출처 | 김형국 목사 「풍성한 삶의 첫걸음」(하나복DNA Network) |
| 형식 | PWA (Progressive Web App) — 별도 설치 없이 브라우저에서 작동 |
| 배포 | GitHub Pages — `https://hanabokdna2026-dot.github.io/firststep/` |
| 색상 | amber 톤 (배경 #FAEEDA, 액센트 #BA7517) |
| 폰트 | 한글 본문은 Noto Serif KR(세리프), UI는 Pretendard(산세리프) |
| 데이터 저장 | 모두 localStorage (백엔드 없음, 사용자 폰에만 저장) |

## 2. 전체 흐름 — 사용자가 앱을 처음 만나서 한 과를 마치기까지

### 2-1. 첫 진입 (온보딩)

| 단계 | 화면 | 내용 |
|---|---|---|
| 1 | 환영 화면 | 제목 + 부제 + "시작하기" 버튼 + 하나복 로고 footer |
| 2 | 이름 입력 | 사용자 이름 받음 (예: "주영") |
| 3 | 속도 선택 | 한 주에 한 과 / 두 과 / 세 과 중 선택 |
| 4 | 알림 시간 설정 | 아침·낮·저녁 알림 받을 시간 (선택사항) |
| 5 | 홈 화면 진입 | 1과 1일 첫째 날부터 시작 |

### 2-2. 일상 흐름 (한 과 = 6일)

```
한 과 = 6일 (월~토)
  하루 = 3 세션 (아침 / 낮 / 저녁)
  
한 세션 = 약 5~10분
```

### 2-3. 한 세션의 흐름 (예: 아침 세션)

```
1. 홈 화면에서 "아침 세션" 카드 누름
2. 시작 화면 (인터스티셜)
   - "먼저 잠시 멈추세요" 메시지
   - 시작 버튼
3. 본문 + 묵상 화면 (세션 타입에 따라 다름 — 아래 4·5·6과별 설명 참조)
4. 한 마디 기도 입력 + 잠잠히 머물기 버튼
5. 잠잠히 머물기 화면 (10초~15초 침묵)
6. 마침 화면
   - "오늘 ___ 세션을 마쳤어요" 메시지
   - 다음 세션이 있으면 "다음으로", 없으면 "오늘은 여기까지"
```

## 3. 화면 구조

### 3-1. 메인 화면들

| 화면 | URL 해시 | 역할 |
|---|---|---|
| 환영 | `#welcome` | 첫 진입 + 하나복 로고 |
| 이름 | `#name` | 사용자 이름 입력 |
| 속도 | `#pace` | 한 주 진도 속도 선택 |
| 알림 | `#notify` | 알림 시간 설정 |
| 홈 | `#home` | 오늘의 3 세션 카드 + 하단 탭바 |
| 여정 | `#journey` | 전체 10과 진도 한눈에 보기 |
| 기록 | `#record` | 지금까지 적은 한 마디 기도 모음 |
| 설정 | `#settings` | 이름·속도·알림·데이터 + 하나복 로고 |
| 세션 시작 | `#session/{type}` | 시작 인터스티셜 |
| 본문/묵상 | `#read/{type}` | 핵심 콘텐츠 화면 |
| 잠잠히 | `#silence/{type}` | 침묵 자리 |
| 마침 | `#done/{type}` | 세션 완료 |

### 3-2. 하단 탭바 (홈·기록·설정)

홈 화면 하단에 항상 보이는 탭. SVG 아이콘 (해 / 책갈피 / 사람 모양). 활성 탭은 amber 색.

### 3-3. 시간 표시

홈 화면 인사말 자리에 "오후 1시 32분" 식의 현재 시간 표시. 1분마다 자동 갱신, 시간대 변경 시 화면도 다시 그림.

## 4. 데이터 구조

### 4-1. lessons.json — 모든 콘텐츠의 저장소

```
data/lessons.json (약 170 KB)
├── lessons (배열)
│   ├── 1과 (id: 1, title: "거듭남의 신비와 축복")
│   │   ├── coreMessage: "..."
│   │   └── days (6일치 배열)
│   │       ├── 1일 (dayIndex: 1)
│   │       │   ├── verseRef: "마가복음 1:14-15"
│   │       │   ├── verses: { saebeon: "...", gaeyeok: "..." }
│   │       │   ├── morning: { ... }
│   │       │   ├── midday: { ... }
│   │       │   ├── evening: { ... }
│   │       │   └── dayLabel: "첫째 날"
│   │       ├── 2일 ...
│   │       └── 6일 ...
│   ├── 2과 ...
│   └── 6과 (현재 작업 완료된 마지막 과)
```

### 4-2. john1.json — 요한복음 1장 절 단위 데이터

```
data/john1.json (약 17 KB)
{
  "book": "요한복음",
  "chapter": 1,
  "totalVerses": 51,
  "verses": [
    { "v": 1, "saebeon": "...", "gaeyeok": "..." },
    { "v": 2, "saebeon": "...", "gaeyeok": "..." },
    ...
    { "v": 51, ... }
  ]
}
```

이 파일은 **4과부터의 통독**에 쓰임. 사용자 페이스로 절 단위 진도 트래킹.

### 4-3. localStorage 저장 항목

| 키 | 내용 |
|---|---|
| `firststep:userName` | 사용자 이름 |
| `firststep:defaultPace` | 기본 속도 (one/two/three) |
| `firststep:weekPace` | 이번 주 속도 |
| `firststep:currentLesson` | 현재 진행 중인 과 (1~10) |
| `firststep:currentDay` | 현재 진행 중인 일 (1~6) |
| `firststep:weekStartDate` | 이번 주 시작 날짜 |
| `firststep:notifyTimes` | 알림 시간 (아침·낮·저녁) |
| `firststep:notifyEnabled` | 알림 켜짐/꺼짐 |
| `firststep:session:{date}:{type}` | 세션 완료 기록 |
| `firststep:dayDone:{lesson}:{day}:{type}` | 일별 마침 기록 |
| `firststep:prayer:{lesson}:{day}:{type}` | 한 마디 기도 |
| `firststep:lords:{lesson}:{day}` | 주기도 자기 말 (5·6과) |
| `firststep:read:요한복음:1:lastVerse` | 통독 마지막 절 (4과~) |
| `firststep:readingSize` | 통독 분량 (3/5/7/10) |

## 5. 한 일(day) 안의 세 세션

### 5-1. 아침 세션 (morning)

**기본 흐름** (1~3과):
1. 시작 인터스티셜
2. 오늘의 말씀 (verseRef + verses)
3. 마음에 머물기 (ponderQuestion 한 갈래)
4. 하나님께 한 마디 (prayerExample + 입력란)
5. 잠잠히 머물기

**4과부터 추가**: 묵상이 두 갈래로 분리
- "잠시 들여다보기" (observeQuestion — 본문 관찰)
- "오늘 내 하루에서" (applyQuestion — 적용)

**5·6과부터 추가**: "주기도 따라 드리기" 카드
- 그날의 주기도 한 부분 (lordsPart)
- 키워드 3개 (lordsKeywords)
- 예시 기도 (lordsExample)
- 자기 말 입력란 (storage에 저장)

**6과만**: "입술로 드리는 고백" 카드 (5과 작업했던 결이 6과로 이동)
- 그날 시편의 한 마디 (confessLine)
- 작은 소리로 두세 번 따라 읽도록 안내

### 5-2. 낮 세션 (midday) — 통독

**1~3과**: 고정 단락 통독
- 정해진 본문 (예: 요 3:1-8)
- 두 번역 토글 (새번역/개역개정)
- "흘려 읽기" 안내 + 한 마디 기도 (3과부터)

**4과부터**: 사용자 페이스 통독 (continuous mode)
- 어제 끝낸 절 다음부터 시작
- 분량 토글 (3·5·7·10분 → 8·16·24·36절)
- 절마다 작은 amber 번호 표시
- "여기까지 읽었어요" 누르면 진도 저장
- 1장 다 읽으면 마무리 화면 ("요한복음 1장을 다 읽으셨어요")

**참고**: 4·5·6과 모두 요한복음 1장에서 사용자 페이스로 진행. 6과 마지막 일에 "다음 한 주 새 과에서 2장으로 이어집니다" 안내.

### 5-3. 저녁 세션 (evening)

**모든 과 공통**:
1. 시작 인터스티셜
2. 그날 아침 본문 다시 보여주기
3. 하루 돌아보기 질문 (reflectQuestion)
4. 한 마디 기도 입력
5. 잠잠히 머물기 (10초)
6. 마침

각 과의 6일째 저녁은 **한 주 마무리** 결로 침묵 시간이 15초로 길어짐.

## 6. 과별 콘텐츠 상세

### 6-1. 1과 — 거듭남의 신비와 축복

**핵심 메시지**: 인간이 다시 태어나는 일, 그것이 거듭남입니다. 그분의 사랑이 우리를 새로 빚어 가십니다.

| 일 | 본문 | 통독 (낮) | 결 |
|---|---|---|---|
| 1 | 막 1:14-15 | 막 1:14-20 | 회개와 복음 |
| 2 | 요 3:16 | 요 3:1-8 | 거듭남 |
| 3 | 요 1:12 ⭐ | 요 1:9-14 | 자녀가 되는 권세 |
| 4 | 요 10:10 | 요 10:1-10 | 풍성한 삶 |
| 5 | 고후 5:17 ⭐ | 고후 5:14-21 | 새로운 피조물 |
| 6 | 갈 2:20 | 갈 2:15-21 | 그리스도와 함께 사는 |

⭐ = 핵심 본문 / 보조는 표시 없음

**아침 묵상**: 한 갈래(`ponderQuestion`)
**낮 통독**: 고정 단락 + 두 번역 토글

### 6-2. 2과 — 인격적인 하나님

**핵심 메시지**: 하나님은 멀리 계신 분이 아닙니다. 우리를 사랑하시고, 우리와 인격적으로 만나기 원하시는 분입니다.

| 일 | 본문 | 통독 (낮) | 결 |
|---|---|---|---|
| 1 | 롬 5:8 ⭐ | 롬 5:6-11 | 우리를 향한 사랑 |
| 2 | 슥 3:17 | 슥 3:14-17 | 사랑하는 자녀 |
| 3 | 사 43:1 ⭐ | 사 43:1-7 | 너는 내 것이라 |
| 4 | 요일 3:16 | 요일 3:11-18 | 사랑의 본 |
| 5 | 롬 8:38-39 ⭐ | 롬 8:31-39 | 끊을 수 없는 사랑 |
| 6 | 요 8:31-32 | 요 8:31-36 | 자유케 하는 진리 |

### 6-3. 3과 — 하나님과 인격적 관계 맺기

**핵심 메시지**: 인격적인 하나님과의 관계는 매일 그분 곁에 머무는 자리에서 자랍니다.

| 일 | 본문 | 통독 (낮) | 결 |
|---|---|---|---|
| 1 | 요 17:3 ⭐ | 요 17:1-11 | 영생은 그분을 아는 것 |
| 2 | 벧전 2:2-3 | 벧전 2:1-10 | 신령한 젖 |
| 3 | 요 15:5 ⭐ | 요 15:1-17 | 포도나무 가지 |
| 4 | 빌 3:8 | 빌 3:1-14 | 그리스도를 아는 지식 |
| 5 | 요 15:14-15 ⭐ | 요 15:9-17 | 친구라 하리라 |
| 6 | 요 14:21 | 요 14:15-27 | 사랑함과 나타냄 |

**3과부터 새 결**: 낮 세션에 한 마디 기도 추가 (`midday.prayerExample`)

### 6-4. 4과 — 하나님의 말씀 누리는 축복

**핵심 메시지**: 말씀은 정보가 아니라 생명입니다. 매일 그 말씀을 누리며, 그분께로 더 가까이 갑니다.

**흐름**: 인도(빛) → 양식 → 뿌리 → 그분께 가는 길 → 살아있는 능력 → 살아내기

| 일 | 본문 | 통독 결 | 결 |
|---|---|---|---|
| 1 | 시 119:105 ⭐ | 요 1장 (사용자 페이스) | 발의 등불 |
| 2 | 마 4:4 | 요 1장 | 모든 말씀으로 |
| 3 | 시 1:1-3 ⭐ | 요 1장 | 시냇가 나무 |
| 4 | 요 5:39-40 | 요 1장 | 나에게로 와야 |
| 5 | 히 4:12 ⭐ | 요 1장 | 살아있고 활력있는 |
| 6 | 약 1:22-25 | 요 1장 | 행하는 자 |

**4과부터의 새 결**:
- **묵상 두 갈래** (관찰 `observeQuestion` + 적용 `applyQuestion`)
- **통독 사용자 페이스** (요한복음 1장, 절 단위 데이터, 분량 토글 3·5·7·10분)
- 통독 마지막 안내: "요한복음 1장을 다 읽으셨어요. 다음 한 주 새 과에서 2장으로 이어집니다"

### 6-5. 5과 — 하나님께 나아가는 축복 (주기도 1 · 하나님 편)

**핵심 메시지**: 하나님께 나아가는 자리, 그곳이 가장 큰 축복입니다. 주기도문은 그 자리를 여는 길입니다.

**결**: 본문은 기도와 하나님 나라를 알아가는 다양한 결, 주기도는 매일 한 부분씩 자기 말로.

| 일 | 본문 | 결 | 주기도 따라 드리기 |
|---|---|---|---|
| 1 | 롬 8:15 ⭐ | 아빠 아버지 | 하늘에 계신 우리 아버지여 |
| 2 | 사 6:1-3 | 거룩하신 분 | 이름이 거룩히 여김을 받으시오며 |
| 3 | 마 6:33 ⭐ | 그의 나라와 의 | 나라가 임하시오며 |
| 4 | 요 6:38 ⭐ | 보내신 분의 뜻 | 뜻이 이루어지이다 |
| 5 | 빌 4:6-7 | 염려 대신 기도 | 한 주에 배운 결 통합 |
| 6 | 막 11:24 | 받은 줄 믿으라 | 하나님 편 전체 마무리 |

**5과부터의 새 결**: "주기도 따라 드리기" 카드 (아침 세션)
- 그날의 주기도 한 부분 (큰 글자, 세리프체)
- 키워드 3개 (각 키워드와 의미 한 줄)
- 예시 기도 (이탤릭)
- 자기 말 입력란 (자동 저장)

**낮 통독**: 요한복음 사용자 페이스 그대로 (4과에서 이어감)

### 6-6. 6과 — 하나님께 나아가 누리는 축복 (주기도 2 · 우리 편 + 시편으로 찬미)

**핵심 메시지**: 하나님께 나아가는 자리, 그곳이 가장 큰 축복입니다. 영과 진리로, 매일 그분 앞에 섭니다.

**결**: 본문은 시편으로 찬미·예배 배우기, 주기도는 매일 우리 편 한 부분.

| 일 | 시편 (묵상) | 입술 고백 | 주기도 따라 드리기 |
|---|---|---|---|
| 1 | 시 100편 ⭐ | "주님이 우리 하나님이심을…" | 일용할 양식을 주시옵고 |
| 2 | 시 95:6-7 | "오너라, 우리가 엎드려 경배하자" | 우리 죄를 사하여 (받는 용서) |
| 3 | 시 84:1-2 ⭐ | "주님께서 계시는 곳이 어찌…" | 우리에게 죄 지은 자를 사하여 (주는 용서) |
| 4 | 시 27:4 | "주님께 청한 것이 한 가지" | 시험과 악에서 구하옵소서 |
| 5 | 요 4:23-24 ⭐ | "참되게 예배하는 사람들이…" | 송영 (영원히 아버지께) |
| 6 | 시 103:1-5 | "내 영혼아, 주님을 찬양하여라" | 주기도 전체 통합 (5·6과 마무리) |

**6과의 새 결 — "입술로 드리는 고백" 카드**
- 시편이 본래 입술로 부르는 노래임을 일깨움
- 작은 소리로 두세 번 따라 읽도록 안내
- amber 좌측 보더 + 옅은 amber 그라데이션 배경

## 10. 콘텐츠 수정하기 — 어디를 어떻게 손볼지

### 10-1. 본문이나 묵상 질문 수정

**파일**: `data/lessons.json`

```
data/lessons.json
└── lessons[과 인덱스].days[일 인덱스].morning
    ├── verses.saebeon     ← 새번역 본문
    ├── verses.gaeyeok     ← 개역개정 본문
    ├── stillIntro         ← 짧은 도입 문단
    ├── observeQuestion    ← 잠시 들여다보기 (4과부터)
    ├── applyQuestion      ← 오늘 내 하루에서 (4과부터)
    ├── ponderQuestion     ← 마음에 머물기 (1~3과)
    ├── prayerExample      ← 한 마디 기도 예시
    ├── confessLine        ← 입술 고백 한 줄 (6과)
    ├── confessIntro       ← 입술 고백 안내 (6과)
    ├── confessRef         ← 입술 고백 출처 (6과)
    ├── lordsPart          ← 주기도 한 부분 (5·6과)
    ├── lordsKeywords      ← 키워드 [{key, meaning}, ...] (5·6과)
    ├── lordsExample       ← 주기도 예시 기도 (5·6과)
    ├── lordsIntro         ← 주기도 안내 (5·6과)
    └── lordsPlaceholder   ← 자기 말 입력란 placeholder (5·6과)
```

### 10-2. 통독 본문 수정

- **1·2·3과 통독**: `data/lessons.json` 안의 `midday.passageText.{saebeon,gaeyeok}`
- **4·5·6과 통독**: `data/john1.json` (요한복음 1장 절 단위)

### 10-3. 화면 안내 문구 수정

`js/screens/` 안의 각 파일. 예: 세션 시작 인사말은 `session-start.js`, 마침 메시지는 `done.js`.

### 10-4. 색상이나 카드 디자인 수정

`css/styles.css`. 모든 색상은 CSS 변수로 정의되어 있어서 한 곳만 바꾸면 전체 적용.

### 10-5. 한 과를 통째로 추가/삭제

- `data/lessons.json`에 새 과 객체 추가 (id 7, 8, 9, 10)
- `js/curriculum.js` (있다면)의 `CURRICULUM_OUTLINE` 배열 동기화

#### ⭐ 셋째 날 — 시편 1:1-3

*키워드*: 시냇가 나무

> 복 있는 사람은 악인의 꾀를 따르지 아니하며, 죄인의 길에 서지 아니하며, 오만한 자의 자리에 앉지 아니하며, 오로지 주님의 율법을 즐거워하며, 밤낮으로 율법을 묵상하는 사람이다. 그는 시냇가에 심은 나무가 철 따라 열매를 맺으며, 그 잎이 시들지 아니함과 같으니, 하는 일마다 잘 될 것이다.

#### · 넷째 날 — 요한복음 5:39-40

*키워드*: 나에게로 와야

> 너희가 성경을 연구하는 것은 영원한 생명이 그 안에 있다고 생각하기 때문이다. 성경은 나에 대하여 증언하고 있다. 그런데 너희는 생명을 얻으려고 나에게로 오기를 거부한다.

#### ⭐ 다섯째 날 — 히브리서 4:12

*키워드*: 살아 있고 활력이 있어

> 하나님의 말씀은 살아 있고, 활력이 있어, 어떤 양날 칼보다도 더 날카롭습니다. 그래서 사람 속을 꿰뚫어 혼과 영을 갈라내고, 관절과 골수를 갈라놓기까지 하며, 마음에 품은 생각과 의도를 밝혀냅니다.

#### · 여섯째 날 — 야고보서 1:22-25

*키워드*: 행하는 자

> 여러분은 말씀을 행하는 사람이 되십시오. 그저 듣기만 하여 자기를 속이는 사람이 되지 마십시오. 말씀을 듣기만 하고 행하지 않는 사람은, 마치 거울에 자기 얼굴을 비추어 보는 사람과 같습니다. 자기 모습을 비추어 보고 떠나가서는, 곧 자기 모습이 어떠하였는지를 잊어버립니다. 그러나 자유롭게 하는 완전한 율법을 들여다보고, 거기에 머물러 있는 사람은, 듣고 나서 잊어버리는 사람이 아니라, 실천하는 사람입니다. 그러한 사람은 그 행함에 복을 받을 것입니다.


### 5과 — 하나님께 나아가는 축복

**핵심 메시지**: 하나님께 나아가는 자리, 그곳이 가장 큰 축복입니다. 주기도문은 그 자리를 여는 길입니다.

#### ⭐ 첫째 날 — 로마서 8:15

*키워드*: 아빠 아버지

> 여러분은 또다시 두려움에 빠뜨리는 종살이의 영을 받은 것이 아니라, 자녀로 삼으시는 영을 받았습니다. 그래서 우리는 그 영으로 하나님을 '아빠, 아버지'라고 부릅니다.

#### · 둘째 날 — 이사야 6:1-3

*키워드*: 거룩 거룩 거룩

> 웃시야 왕이 죽던 해에, 나는 높이 들린 보좌에 앉아 계시는 주님을 뵈었는데, 그 옷자락이 성전에 가득 차 있었다. 그분을 둘러서서 스랍들이 모시고 있었는데, 스랍들은 저마다 날개를 여섯 개씩 가지고 있었다. 둘로는 자기들의 얼굴을 가리고, 둘로는 자기들의 발을 가리고, 나머지 둘로는 날고 있었다. 그들이 서로 화답하며 외쳤다. '거룩하시다, 거룩하시다, 거룩하시다, 만군의 주님! 온 땅에 그의 영광이 가득하시다.'

#### ⭐ 셋째 날 — 마태복음 6:33

*키워드*: 먼저 그의 나라를 구하라

> 너희는 먼저 하나님의 나라와 하나님의 의를 구하여라. 그리하면 이 모든 것을 너희에게 더하여 주실 것이다.

#### ⭐ 넷째 날 — 요한복음 6:38

*키워드*: 내 뜻 아닌 그분의 뜻

> 그것은, 내가 내 뜻을 행하려고 하늘에서 내려온 것이 아니라, 나를 보내신 분의 뜻을 행하려고 왔기 때문이다.

#### · 다섯째 날 — 빌립보서 4:6-7

*키워드*: 염려 대신 기도로

> 아무 것도 염려하지 말고, 모든 일에 감사하는 마음으로 기도와 간구로 여러분의 간청을 하나님께 알리십시오. 그리하면 사람의 헤아림을 뛰어 넘는 하나님의 평화가 여러분의 마음과 생각을 그리스도 예수 안에서 지켜 줄 것입니다.

#### · 여섯째 날 — 마가복음 11:24

*키워드*: 받은 줄로 믿으라

> 그러므로 내가 너희에게 말한다. 너희가 기도하면서 구하는 것은 무엇이든지, 이미 그것을 받은 줄로 믿어라. 그러면 너희에게 그대로 이루어질 것이다.


### 6과 — 하나님께 나아가 누리는 축복

**핵심 메시지**: 하나님께 나아가는 자리, 그곳이 가장 큰 축복입니다. 영과 진리로, 매일 그분 앞에 섭니다.

#### ⭐ 첫째 날 — 시편 100편

*키워드*: 기쁨으로 섬겨라

> 온 땅이여, 주님께 환호성을 올려라. 기쁨으로 주님을 섬기며, 환호성을 올리면서 그분 앞으로 나아가거라. 너희는 주님이 하나님이심을 알아라. 그분이 우리를 지으셨으니, 우리는 그분의 것이요, 그분의 백성이요, 그분이 기르시는 양이다. 감사의 노래를 부르며, 그분의 문으로 들어가거라. 찬양의 노래를 부르며, 그분의 뜰로 들어가거라. 주님께 감사를 드리며, 그분의 이름을 찬양하여라. 주님은 선하시며, 그 인자하심이 영원하며, 그 성실하심이 대대에 이르기 때문이다.

#### · 둘째 날 — 시편 95:6-7

*키워드*: 엎드려 경배하자

> 오너라, 우리가 엎드려 경배하자. 우리를 지으신 주님 앞에 무릎을 꿇자. 그분은 우리의 하나님이시요, 우리는 그분이 기르시는 백성이며, 그분의 손이 보살펴 주시는 양이다.

#### ⭐ 셋째 날 — 시편 84:1-2

*키워드*: 사모하다

> 만군의 주님, 주님께서 계시는 곳이 어찌 그리도 사랑스러운지요. 내 영혼이 주님의 성전 뜰을 그리워하다가, 지쳐 버렸습니다. 내 마음과 살과 피가 살아 계시는 하나님께 부르짖습니다.

#### · 넷째 날 — 시편 27:4

*키워드*: 한 가지

> 주님께 청한 것이 하나 있으니, 나는 오직 그것을 구하리라. 그것은 한평생 주님의 집에 살면서, 주님의 자비로우신 모습을 보는 것과, 성전에서 주님과 의논하면서 살아가는 것이다.

#### ⭐ 다섯째 날 — 요한복음 4:23-24

*키워드*: 영과 진리로

> 참되게 예배하는 사람들이 영과 진리로 아버지께 예배할 때가 온다. 지금이 바로 그 때이다. 아버지께서는 이렇게 예배하는 사람들을 찾으신다. 하나님은 영이시다. 그러므로 하나님께 예배하는 사람은 영과 진리로 예배를 드려야 한다.

#### · 여섯째 날 — 시편 103:1-5

*키워드*: 내 영혼아 송축하라

> 내 영혼아, 주님을 찬양하여라. 내 속에 있는 모든 것아, 거룩한 그 이름을 찬양하여라. 내 영혼아, 주님을 찬양하여라. 그 모든 은혜를 잊지 말아라. 주님은 너의 모든 죄를 용서해 주시는 분, 너의 모든 병을 고쳐 주시는 분, 너의 생명을 무덤에서 속량해 주시는 분, 너에게 인자와 긍휼로 관을 씌워 주시는 분, 평생에 네 소원을 좋은 것으로 채워 주셔서, 네 젊음을 독수리처럼 늘 새롭게 해주시는 분이시다.

## 부록 C — 주기도 따라 드리기 — 키워드와 예시 전체

앱 안 카드에서 사용자가 매일 만나는 결.

### 5과

#### 첫째 날 — 하늘에 계신 우리 아버지여

*안내*: 이번 주는 주기도문의 첫 부분을 자기 기도로 만들어보겠습니다. 외우는 게 아니라, 그 결로 자기 마음을 드리는 거예요.

**키워드**:

- **하늘에 계신** — 그분은 만물의 근원, 우리가 닿을 수 없는 분
- **아버지** — 그런 분과 우리 사이는 자녀의 자리
- **우리** — 나만이 아닌, 형제자매와 함께 부르는 자리

**예시 기도**: "하나님 아버지, 하늘에 계신 그 크신 분을 아버지라 부를 수 있게 해주셔서 감사합니다. 오늘도 자녀로 주님 앞에 서겠습니다."

---

#### 둘째 날 — 이름이 거룩히 여김을 받으시오며

*안내*: 오늘은 주기도문의 두 번째 부분 — 그 이름이 거룩히 여김을 받으시기를 구하는 자리.

**키워드**:

- **이름** — 그분이 누구신지를 드러내는 자리
- **거룩히 여김** — 세상에서 그분이 그분 되심으로 인정받는 것
- **받으시오며** — 내 삶과 우리 공동체를 통해 그렇게 되기를

**예시 기도**: "주님의 이름이 제 삶에서 거룩히 드러나게 해주세요. 제가 부족함으로 주님의 이름이 더럽혀지지 않게 도와주세요."

---

#### 셋째 날 — 나라가 임하시오며

*안내*: 오늘은 주기도문의 세 번째 부분 — 그 나라가 임하기를 구하는 자리.

**키워드**:

- **나라** — 하나님의 통치 — 예수님의 중심 사상
- **임하시오며** — 지금 내 자리에, 그리고 마침내 온전히
- **오시기를 기다리며 살기** — 수동적 도피가 아니라 적극적 동참

**예시 기도**: "주님, 오늘 제가 있는 자리에 주님의 통치가 임하게 해주세요. 어둠 가운데 주님 나라가 속히 오시기를 구합니다."

---

#### 넷째 날 — 뜻이 하늘에서 이루어진 것 같이 땅에서도 이루어지이다

*안내*: 오늘은 주기도문의 네 번째 부분 — 그분의 뜻이 이루어지기를 구하는 자리.

**키워드**:

- **뜻** — 그분이 원하시는 것 — 내 뜻이 아닌
- **하늘에서** — 이미 온전히 이루어지는 자리
- **땅에서도** — 내 삶의 자리에서도, 나를 통해서도

**예시 기도**: "주님, 제 뜻이 아니라 주님의 뜻이 제 삶에서 이루어지게 해주세요. 그 뜻에 제가 동참하게 해주세요."

---

#### 다섯째 날 — 하늘에 계신 우리 아버지여 / 이름이 거룩히 / 나라가 임하시오며 / 뜻이 이루어지이다

*안내*: 오늘은 한 주에 배운 주기도 결을 다시 한번 자기 기도로 드려보세요. 하늘 아버지부터 뜻이 이루어지이다까지.

**키워드**:

- **통합** — 한 주에 배운 네 결을 하나의 흐름으로
- **외우기보다** — 그 결대로 자기 마음을 드리는 자리
- **느린 호흡으로** — 한 부분씩 천천히, 자기 말로

**예시 기도**: "하늘에 계신 아버지, 주님이 만물의 주이심을 압니다. 그 이름이 제 삶에서 거룩히 드러나게 해주시고, 주님 나라가 제 자리에 임하시며, 주님의 뜻이 오늘도 이루어지게 해주세요."

---

#### 여섯째 날 — 하늘에 계신 우리 아버지여 ~ 뜻이 이루어지이다 (전체 통합)

*안내*: 한 주의 마무리에 주기도문의 하나님 편 결을 통째로 자기 말로 한 번 더 드려보세요. 한 주 동안 익힌 결이 어떻게 자기 결로 자라났는지 발견하게 됩니다.

**키워드**:

- **한 주 마무리** — 배운 결을 한 호흡에 드려보기
- **다음 주** — 이어지는 6과에서는 우리 편 기도를
- **신뢰** — 받은 줄로 믿고 기도를 마침

**예시 기도**: "하늘에 계신 우리 아버지, 그 이름이 제 삶에서 거룩히, 그 나라가 제 자리에 임하시며, 그 뜻이 오늘도 이루어지게 해주세요. 받은 줄로 믿고 마칩니다."

---

### 6과

#### 첫째 날 — 오늘 우리에게 일용할 양식을 주시옵고

*안내*: 이번 주는 주기도문 두 번째 부분 — 우리 자신을 위한 기도를 배웁니다. 매일 시편 묵상과 함께 자기 말로 드려보세요.

**키워드**:

- **일용할** — 매일매일, 축적이 아닌 매일 의지하는 자리
- **양식** — 생존을 위한 것이자 그분이 주시는 모든 것
- **주시옵고** — 내가 얻는 것이 아닌 그분이 주시는 것

**예시 기도**: "주님, 오늘 하루 필요한 양식을 주신 것에 감사드립니다. 더 많이 쌓는 게 아니라, 매일 주님만 의지하며 살게 해주세요."

---

#### 둘째 날 — 우리 죄를 사하여 주시옵고

*안내*: 오늘은 주기도문의 다섯 번째 부분 — 우리 죄를 사하여 주시기를 구합니다.

**키워드**:

- **우리 죄** — 내가 인정하고 가져오는 죄
- **사하여** — 용서 — 그분만 하실 수 있는 일
- **주시옵고** — 값없이 받는 자리

**예시 기도**: "주님, 오늘도 제 죄를 가져옵니다. 십자가의 사랑으로 저를 용서해 주세요."

---

#### 셋째 날 — 우리가 우리에게 죄 지은 자를 사하여 준 것 같이

*안내*: 오늘은 주기도문의 같은 결 두 번째 — 우리도 형제를 용서하는 자리.

**키워드**:

- **우리도** — 받은 용서를 흘려보내는 자리
- **죄 지은 자를** — 내가 용서하기 어려운 그 사람
- **사하여 준 것 같이** — 받은 용서가 진짜였다면 흘러갈 것

**예시 기도**: "주님, 제가 용서받았듯 저도 그 사람을 용서하게 해주세요. 어렵다면 그 어려움도 주님께 가져갑니다."

---

#### 넷째 날 — 우리를 시험에 들게 하지 마시옵고, 다만 악에서 구하시옵소서

*안내*: 오늘은 주기도문의 여섯 번째 부분 — 시험에 들지 않게, 악에서 구해주시기를.

**키워드**:

- **시험** — 유혹 — 자기 욕심에 끌려가는 자리
- **악에서** — 사탄의 도발과 세상의 어둠
- **구하시옵소서** — 혼자 싸우지 않고 그분께 의탁

**예시 기도**: "주님, 오늘도 시험과 악 가운데 살아갑니다. 저를 지켜주시고 끌고 가지 못하게 해주세요."

---

#### 다섯째 날 — 나라와 권세와 영광이 영원히 아버지께 있사옵나이다

*안내*: 오늘은 주기도문의 마지막 송영 — 모든 것이 그분께 돌아가는 자리.

**키워드**:

- **나라와 권세와 영광** — 이 세상이 누구의 것인가
- **영원히** — 잠깐이 아닌, 끝이 없는
- **아버지께** — 모든 것이 그분께 돌아감

**예시 기도**: "주님, 모든 나라와 권세와 영광이 영원히 주님께 있습니다. 제 인생도 주님께 돌려드립니다."

---

#### 여섯째 날 — 주기도문 전체 (하늘 아버지부터 송영까지)

*안내*: 한 주의 마무리에 주기도문 전체를 자기 말로 드려보세요. 5·6과를 통해 배운 결이 어떻게 자기 기도가 되었는지 발견하게 됩니다.

**키워드**:

- **전체 통합** — 5·6과의 모든 결을 한 호흡에
- **외우기보다** — 자기 말로, 자기 결로
- **두 주 마무리** — 기도하는 사람으로 살아갈 첫걸음

**예시 기도**: "하늘에 계신 우리 아버지, 그 이름이 거룩히, 그 나라가 임하시며, 그 뜻이 이루어지게 해주세요. 오늘 양식을 주시고, 죄를 용서하시며 저도 용서하게 하시고, 시험과 악에서 구해주세요. 모든 영광이 영원히 주님께 있습니다."
